{# Switch for "do not look up device names through DNS" (nmap -n), with an (i) hover card. Needs `prefix` ('ns' / 'rescan' / 'dd'). Shown for every scan type except Custom (the whole Advanced panel is hidden there): Discovery does reverse DNS too. The checkbox keeps its name (no_dns) and id (_dns_input): the forms and scripts read `.checked`. With it on, neither nmap nor the app asks a DNS server for device names; NetBIOS names (asked from the device itself) are still read. #}
