{# "Show more" bar for the Scan Result tables (scan_detail.html, vuln_scan_detail.html). A host with more than `preview_rows` ports shows only its first rows; the rest carry .host-row-extra and stay hidden until the bar under the host (its own , markup in _host_more_bar.html) is clicked. The bar is a plain white row with a hairline on top, starting under the Port column so it reads as part of the port list, and in it one outlined pill button (the owner's merge of two mock-ups: B, a light blue link row, and C, an outlined pill). It used to be a pale slate band from the Port column to the right edge, which left a white notch under the IP / MAC / OS cells and pushed the note to the far right; there is no fill now, so nothing is left over. The pill holds a chevron and how many ports are hidden (data-hidden, "แสดงอีก N พอร์ต"), then after a hairline a quiet note of what is in them: their states when some are not open and, in a vulnerability scan, their CVEs by severity (hidden_port_summary() in app.py). While the host is open the note goes away and the label reads "แสดงน้อยลง". The hidden rows are collapsed, not display:none: a collapsed row has no height but its cells still count when the browser sizes the columns, so every column keeps the same width whether a host is open or closed (no jump when the bar is clicked). For the same reason the IP/MAC/OS (and Actions) cells always span all of the host's rows. #}
