{# Switch for the UDP option (a second nmap run: the 12 common UDP ports, only on the devices the first run found online), with an (i) hover card. Needs `prefix` ('ns' / 'rescan' / 'dd'). Shown for Intense and Vulnerability scans only (hidden for the other types by updateScanAdvancedForType() in base.html; the whole Advanced panel is hidden for Custom). The checkbox keeps its name (udp) and id (_udp_input). It excludes nothing: the server refuses it only without Administrator rights / Npcap or on more than 64 addresses, and says so in a notice. #}
หลังสแกนรอบแรกเสร็จ ระบบสแกน UDP เป็นรอบที่ 2 กับอุปกรณ์ IPv4 ที่รอบแรกพบว่าออนไลน์ ใน 12 พอร์ตที่พบบ่อย: 53, 67, 69, 123, 137, 161, 500, 520, 623, 1434, 1900, 5060 (เช่น DNS, SNMP, NTP, SIP) ผลพอร์ต TCP ไม่เปลี่ยน พอร์ต UDP ที่ไม่ตอบกลับจะแสดงเป็น open|filtered หมายถึงไม่ทราบว่าเปิดหรือถูกกรอง ไม่ใช่พอร์ตที่เปิด และพอร์ตส่วนใหญ่มักแสดงแบบนี้ Vulnerability Scan ค้นหา CVE เฉพาะพอร์ต UDP ที่เปิด ต้องรันระบบด้วยสิทธิ์ Administrator หรือ root และมี Npcap รับเป้าหมายได้ไม่เกิน 64 ที่อยู่ (นับทั้งช่วงที่ระบุ ไม่ใช่เฉพาะอุปกรณ์ที่ออนไลน์) ใช้เวลานานขึ้นมาก ระบบหยุดงานที่ใช้เวลาเกิน 6 ชั่วโมงรวมทั้ง 2 รอบ (8 ชั่วโมงเมื่อเปิดสแกนแบบนุ่มนวล)
