{# Draggable column borders for tables marked data-resizable (the Scan Result and CVE tables). When the table is first shown, its current column widths are frozen into a and it switches to table-layout: fixed, so nothing moves. A handle on each header border (every column but the last, and none before an untitled buttons column) trades width between the two columns beside it, so the table keeps filling its card. A column never goes below its own minimum (its widest word or value, hidden rows included), which keeps the protection auto layout gave against overlapping text; a card narrower than all the minimums scrolls sideways as before. Double-click a handle to restore the original widths. With a handle focused, the arrow keys nudge it (Shift = bigger steps). #}
